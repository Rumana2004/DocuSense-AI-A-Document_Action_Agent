DocuSense AI – A Document Action Agent

DocuSense AI is an intelligent multi-agent document analysis and decision system designed to process invoices, resumes, and complaints in real time.

Features

- Intelligent document classification
- Automated information extraction
- Data validation and anomaly detection
- Invoice risk analysis & payment decision
- Resume candidate evaluation
- Complaint prioritization
- AI-generated summaries & responses
- CrewAI-based multi-agent orchestration
- Offline AI processing using Ollama

Technologies Used

- Python
- Streamlit
- CrewAI
- Ollama
- OCR
- NLP
- Regex

How to Run

ollama run phi
streamlit run app.py
